# 00 · 准备工具与驱动

> 第一次做的话，从这页开始。全部装好后跳到 [README.md](README.md) 的场景导航。

## 1. 装 RK USB 驱动

盒子通过 USB 连电脑时要先装 Rockchip 的驱动，否则设备管理器里是个未知设备。

### 步骤

1. 拿到 `DriverAssitant_v5.14.zip`（见 [tools/README.md](tools/README.md) 的下载地址）
2. 解压，右键 `DriverInstall.exe` → **以管理员身份运行**
3. 点「驱动安装」，等提示"安装驱动成功"
4. **重启电脑**（重要，不重启有时驱动不生效）

### 验证装好了

盒子断电，短接进 MASKROM（见 [04-救砖-MASKROM.md](04-救砖-MASKROM.md)），插 USB 到电脑，看设备管理器：

| 状态 | 显示 |
|---|---|
| ✅ 正常 | `Rockusb Device` / `Rockchip USB Device` 在「通用串行总线设备」下 |
| ❌ 没装好 | 未知设备 / 黄色感叹号 |

## 2. 准备 upgrade_tool

命令行刷机工具，比图形界面可靠（图形版 RKDevTool 是 32 位的，写大文件会「内存不足」）。

### 获取

见 [tools/README.md](tools/README.md)。解压后得到：

```
upgrade_tool.exe      ← 主程序
config.ini            ← 配置（别动）
```

### 验证

```powershell
cd 到 upgrade_tool.exe 所在目录
upgrade_tool -h
```

会打印用法。如果提示"不是内部或外部命令"，说明没在当前目录，用 `.\upgrade_tool.exe` 或 `cd` 进去。

> **建议把 upgrade_tool 所在目录加到 PATH**，后面命令能直接敲 `upgrade_tool`。
> 或者把 `upgrade_tool.exe` 复制到你要执行命令的目录（一般是手册所在目录）。

### 第一次连线测试

盒子进 MASKROM 后：

```powershell
upgrade_tool ld
```

| 输出 | 含义 |
|---|---|
| `DevNo=1 Vid=0x2207,Pid=0x350a,LocationID=... Maskrom` | ✅ 识别为 MASKROM |
| `... Loader` | 识别为 LOADER（也能用，但某些操作会被拒） |
| `not found any devices` | ❌ 线/驱动/短接有问题 |

## 3. 准备写盘工具（写 U 盘系统用）

| 工具 | 用途 | 备注 |
|---|---|---|
| **Rufus** | 写 .img 到 U 盘 | 提示模式必须选 **DD 镜像模式** |
| balenaEtcher | 写 .img / .img.gz 到 U 盘 | 支持 gz，不用先解压 |

⚠️ **Rufus 不认 .gz**，如果拿到的是 `.img.gz`，要么用 Etcher，要么先解压。

## 4. 准备串口（强烈建议，不是必需）

没有串口你只能靠"能不能出画面"猜问题，有串口能直接看到卡在哪一行。

### 接线

| 盒子 | USB 转串口小板 |
|---|---|
| GND | GND |
| TXD | RXD |
| RXD | TXD |
| （不要接 VCC） | — |

### 参数

```
波特率 1500000    数据位 8    停止位 1    校验 None    流控 None
```

> ⚠️ **1500000 是特殊波特率**，很多终端软件默认没有。用 MobaXterm / SecureCRT / PuTTY（新版本支持手输）可以填。
> 如果只能选标准波特率，选 115200 会出乱码——这是正常的，说明波特率不对。

### 常用终端软件

| 软件 | 优点 |
|---|---|
| MobaXterm | 能自定义波特率，顺手 |
| PuTTY | 轻量 |
| minicom / picocom（Linux） | `picocom -b 1500000 /dev/ttyUSB0` |

## 5. 检查清单

动手前对照一遍：

- [ ] RK USB 驱动装好且重启过
- [ ] `upgrade_tool ld` 能识别设备
- [ ] 手册所有文件在 `files/` 下，`SHA256SUMS.txt` 校验通过
- [ ] 有短接工具（镊子/回形针）
- [ ] 串口能用（如果准备了）
- [ ] 知道盒子背面短接点在哪（见 [04-救砖-MASKROM.md](04-救砖-MASKROM.md)）

### 校验文件完整性

```powershell
cd handmade\files
# Windows PowerShell
Get-FileHash * -Algorithm SHA256
```

或 Git Bash：

```bash
cd handmade/files && sha256sum -c SHA256SUMS.txt
```

全部 OK 才继续。**校验不通过别刷**——文件坏了刷进去必然起不来。
