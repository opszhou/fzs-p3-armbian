# 03 · 只更新引导固件

> 适用：系统能正常跑，只想换引导（H ↔ G 互切、版本升级）。
> 耗时：**5 分钟**，不动系统、不动数据、不动分区表。

## 为什么要换模式

| 你要做的事 | 需要模式 |
|---|---|
| 日常使用、从 U 盘启动系统 | **H**（host） |
| 刷机、救砖、把 eMMC 当 U 盘给电脑看 | **G**（gadget） |

两个模式**互斥**，因为板子只有一个 USB 口：

```
H：USB 口当主机 → 能读 U 盘，不能被电脑识别
G：USB 口当设备 → 电脑能读写 eMMC，读不了 U 盘
```

启动时串口会打印当前模式，不会搞错：

```
+-------+----------+---------+-------+
| MODE  | USB-boot | rockusb | UMS   |
+-------+----------+---------+-------+
| L10-H |   YES    |   no    |  no   |  <== active
| L10-G |    no    |   YES   |  YES  |
+-------+----------+---------+-------+
```

## 方法 A：系统里直接 dd（推荐）

**前提**：系统能启动，能 SSH 或串口登录。

### 步骤

```bash
# 1) 把固件传到盒子上（在电脑上执行）
scp files/u-boot-L10-H.bin root@<盒子IP>:/root/

# 2) 登录盒子后，写入 eMMC 引导区（LBA 0x40 = 64）
sudo dd if=/root/u-boot-L10-H.bin of=/dev/mmcblk0 bs=512 seek=64 conv=fsync && sync

# 3) 校验
sudo dd if=/dev/mmcblk0 bs=512 skip=64 count=18365 status=none | sha256sum
```

第 3 步输出必须等于：

```
c5e17bfb817d6ba447381fd6b73b8615e32abfbd1ba472e082b0563db10657fe   （H 模式）
293ce97d0299eb6b2e5b30a20dda65f36824fc32cf133860e2ff3ab934f18b03   （G 模式）
```

**不需要重启到特殊模式**，写入时系统正常跑，互不干扰（系统在别的分区/别的盘）。

### 一键切换脚本

如果盒子上已有 `p3boot`，可以更简单：

```bash
# 把固件放到 /root 后
sudo dd if=/root/u-boot-L10-G.bin of=/dev/mmcblk0 bs=512 seek=64 conv=fsync && sync && reboot
```

### 注意

- **不要**写 `seek=0`（会覆盖分区表）
- `seek=64` 是引导区的固定偏移，写错位置板子就起不来
- 写的时候系统还在跑，**别断电**

## 方法 B：LOADER 模式（系统起不来时）

**前提**：设备能被 `upgrade_tool ld` 识别为 LOADER。

### 怎么进 LOADER

| 当前模式 | 操作 |
|---|---|
| **G 模式** | 串口 3 秒内按 `r` → 自动进 rockusb LOADER |
| **H 模式** | 进不了（USB 是主机）→ 只能走 [04-救砖-MASKROM.md](04-救砖-MASKROM.md) |

### 步骤

```powershell
# 1) 确认设备
upgrade_tool ld

# 2) 加载 loader（LOADER 模式下也建议做，避免权限问题）
upgrade_tool db files\MiniLoaderAll_p3_l1.bin

# 3) 写引导
upgrade_tool wl 0x40 files\u-boot-L10-H.bin

# 4) 校验
upgrade_tool rl 0x40 0x47BD readback.bin
sha256sum readback.bin
```

> `0x47BD` = 18,365 扇区（9,402,880 / 512）

## 方法 C：U 盘 + U-Boot 命令行（无系统、无电脑）

**前提**：H 模式（USB 主机可用），有一个 FAT32 U 盘。

### 步骤

1. 把 `u-boot-L10-G.bin` 拷到 U 盘根目录，**改名为 `uboot.bin`**（8.3 文件名，避免兼容问题）
2. 盒子插 U 盘，上电，**3 秒内按 `r` 停在 `=>`**
3. 执行：

```
=> usb start
=> fatload usb 0:1 0x02000000 uboot.bin
=> mmc dev 0
=> mmc write 0x02000000 0x40 0x47BD
=> reset
```

| 命令 | 作用 |
|---|---|
| `usb start` | 启动 USB 主机，识别 U 盘 |
| `fatload` | 把文件读进内存 `0x02000000` |
| `mmc write <addr> <lba> <cnt>` | 从内存写到 eMMC：起始 `0x40`，写 `0x47BD` 个扇区 |

---

## 三种方法对比

| 方法 | 需要系统 | 需要电脑 | 需要短接 | 速度 | 适用 |
|---|---|---|---|---|---|
| **A. dd** | ✅ | ❌（SSH 要在网络里） | ❌ | 秒级 | 最推荐 |
| **B. LOADER** | ❌ | ✅ | 视情况 | 秒级 | 系统坏了但设备能识别 |
| **C. U-Boot + U 盘** | ❌ | ❌ | ❌ | 秒级 | 现场无电脑 |

## 换完怎么验证

断电 10 秒，上电，串口应该看到：

**换成 H 后**：

```
+-------+----------+---------+-------+
| MODE  | USB-boot | rockusb | UMS   |
+-------+----------+---------+-------+
| L10-H |   YES    |   no    |  no   |  <== active
| L10-G |    no    |   YES   |  YES  |
+-------+----------+---------+-------+
```

**换成 G 后**：`<== active` 移到 L10-G 那行。

再确认行为：

| 模式 | 测法 | 期望 |
|---|---|---|
| H | 插 U 盘上电 | 从 U 盘启动，日志有 `USB XHCI` + `usb_mass_storage` |
| G | 串口按 `r` | 打印 `Entering rockusb loader`，电脑能识别 LOADER |

## 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 写完起不来，串口无输出 | 写错偏移（不是 `0x40`） | 重新短接刷，确认 `seek=64` |
| 写完起不来，但能进 MASKROM | 文件损坏 | 校验 `files/SHA256SUMS.txt` |
| `wl` 报 `Switch storage failed` | LOADER 模式的 uboot 不支持 | 先 `db` 加载 loader，或短接进 MASKROM |
| G 模式按 `r` 不进 rockusb | **旧版固件的 bug**（已修） | 换 `files/` 里的新固件 |
| H 模式插 U 盘不起系统 | 正常，H 模式才支持 U 盘启动 | 确认模式表里 `<== active` 在 H 行 |
