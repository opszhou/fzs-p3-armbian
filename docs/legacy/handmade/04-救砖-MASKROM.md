# 04 · 救砖：短接进 MASKROM

> 适用：盒子完全没反应 / 黑屏 / 串口无输出 / 刷坏了起不来。
> **这是永远有效的最后手段**——MASKROM 是芯片内部固化的 BootROM，刷不掉。

## 为什么短接能救

RK3566 上电时会先跑芯片内部固化的 **BootROM**，它做两件事：

```
① 从 eMMC 的 0x40 读 IDB（初始化引导）→ 有 → 正常启动
② 没有 IDB / IDB 无效 → 停在 USB 下载模式（MASKROM），等电脑下发 loader
```

短接 eMMC 的 **CLK 和 GND** 会让 eMMC 不响应，BootROM 读不到 IDB，就落到 ②。

**所以短接不是"强制"，是"骗"**——让芯片以为 eMMC 坏了，走救砖通道。

---

## 找到短接点

位置：**主板背面，eMMC 芯片附近的两个圆点**（丝印上通常标 CLK / GND，也可能没标）。

```
┌─────────────────────────────┐
│  主板背面                     │
│                             │
│   ┌──────┐                  │
│   │ eMMC │    ●  ●          │  ← 这两个圆点（相距 1~2 mm）
│   └──────┘                  │
│                             │
└─────────────────────────────┘
```

**判断方法**：

1. 找 eMMC 芯片（最大的一颗 BGA 芯片，丝印 `KLMAG1JETD` 之类）
2. 芯片旁边找**两个裸露的圆形焊盘**，距离 1~2 mm
3. 用万用表量：一个对地（GND）通、一个不通 → 不通的那个是 CLK

> 没有万用表也行：这类板子的短接点通常是 eMMC 旁唯一的一对圆点，挨个试也行（短接错了不会烧，只是不进 MASKROM）。

---

## 操作步骤（关键在时序）

### 正确时序

```
1. 拔掉电源（彻底断电）
2. 用镊子短接两个圆点
3. 保持短接，插上 USB 线到电脑
4. 保持短接，插上电源
5. 数 1~2 秒 → 松开镊子
6. 电脑端确认设备出现
```

### 常见错误

| 错误 | 后果 |
|---|---|
| 上电后才短接 | ❌ 无效，BootROM 已经跑完了 |
| 一直短接不放 | ⚠️ 有时能进，但建议 1~2 秒后松开 |
| 短接时手抖断开 | ⚠️ 可能进 LOADER 而不是 MASKROM |

### 确认进的是 MASKROM

```powershell
upgrade_tool ld
```

| 输出 | 状态 | 能不能刷 |
|---|---|---|
| `... Maskrom` | ✅ MASKROM | 能，最稳 |
| `... Loader` | ⚠️ LOADER | 能，但某些操作会被厂商 uboot 拒 |
| `not found any devices` | ❌ 没连上 | 见下方排查 |

### 设备管理器确认（Windows）

「通用串行总线设备」下应出现：

- `Rockusb Device`（MASKROM 时）
- 或 `Rockchip USB Device`

黄色感叹号 = 驱动没装好 → 回 [00-准备工具与驱动.md](00-准备工具与驱动.md)。

## 进 MASKROM 后干什么

### 如果只是救引导（5 分钟）

```powershell
upgrade_tool db files\MiniLoaderAll_p3_l1.bin
upgrade_tool wl 0x40 files\u-boot-L10-H.bin
upgrade_tool rl 0x40 0x47BD readback.bin
sha256sum readback.bin     # 与 SHA256SUMS.txt 比对
```

断电 10 秒 → 上电。

### 如果要重装系统（30 分钟）

见 [02-刷系统到eMMC.md](02-刷系统到eMMC.md)，从「三、先加载 loader」开始。

## 救砖失败怎么办

按顺序排查：

### 1. USB 完全没反应

| 检查 | 怎么做 |
|---|---|
| **换 USB 线** | 最常见原因。必须是**数据线**，很多线只能充电 |
| **换 USB 口** | 用主板后置 USB2.0 口，别用前面板 / 别用 hub |
| **换电脑** | 排除电脑 USB 口问题 |
| **确认驱动** | 设备管理器有没有黄色感叹号 |
| **重新短接** | 时序错了，重来一次 |

### 2. 能进 MASKROM 但 `db` 失败

```
Open loader failed(err=-1)
```
→ **文件路径错**。检查 `MiniLoaderAll_p3_l1.bin` 是否在当前目录，路径有没有空格没引号。

```
Download Boot Fail
```
→ USB 通信不稳，换线/换口。

### 3. `db` 成功但 `wl` 报错

```
Error: Execute: Switch storage to EMMC failed
```
→ 说明 `db` 没真正生效（设备还在跑旧 uboot）。
- 重新短接进 MASKROM（确认 `ld` 显示 `Maskrom` 不是 `Loader`）
- 再 `db` 一次

### 4. 写完还是起不来

| 可能 | 验证 |
|---|---|
| 写的位置错了 | 确认 `wl 0x40`（不是 `0x0`） |
| 文件坏了 | `sha256sum` 比对 `files/SHA256SUMS.txt` |
| 模式用错 | 想 U 盘启动必须刷 **H**，不是 G |
| eMMC 物理损坏 | 罕见；`upgrade_tool ld` 能看到设备说明芯片还在 |

### 5. 完全救不回来

如果连 MASKROM 都进不去：

- eMMC 芯片物理损坏 → 需要换芯片（BGA 返修，不现实）
- 供电问题 → 检查 5V 电源是否正常
- **这块板子基本报废**

> 实际概率很低。经手过的板子里，只要短接时序对、线材好，没有救不回来的。

---

## MASKROM vs LOADER：什么时候用哪个

| | MASKROM | LOADER |
|---|---|---|
| 怎么进 | 短接 | 串口按 `r`（仅 G 模式）/ 原厂 recovery 键 |
| 能力 | 只有 BootROM，需先 `db` | 完整 uboot，能力全 |
| 稳定性 | ✅ 最稳 | ⚠️ 看厂商 uboot 实现 |
| 需要短接 | ✅ | ❌ |

**能进 LOADER 就用 LOADER（省事），进不去或报错就短接。**

---

## 一个重要的提醒

短接**不会损坏任何东西**。短接错误的位置最多是不进 MASKROM，不会烧板子。

真正危险的是**写入过程中断电**——那会让 eMMC 半写，但即使这样也能重新短接重刷。

所以：**大胆短接，谨慎断电**。
