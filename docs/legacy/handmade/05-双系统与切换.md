# 05 · 双系统（U 盘系统 + eMMC 系统）

> 适用：想一台机器装两套系统，按需切换。
> 耗时：U 盘系统 20 分钟，eMMC 系统另算（见 02）。

## 架构

```
eMMC 14.7GB  ← 主系统（读 240 MB/s）
  ├─ 引导区 0x40：L10 固件（H 或 G）
  ├─ p1 512MB：boot（内核 + dtb + extlinux）
  └─ p2 13.9GB：rootfs

U 盘 14.9GB  ← 第二系统（读 34.5 / 写 7.1 MB/s）
  ├─ p1 384MB：boot
  └─ p2 14.4GB：rootfs

L10-H 引导 → 按菜单或 p3boot 决定启动哪个
```

**两个系统互不影响**：引导在 eMMC 的 `0x40`，系统各自在自己的盘上。

---

## 为什么要用 H 模式

双系统的核心是「选从哪个盘启动」，只有 **H 模式**能读 U 盘：

| 模式 | 双系统可用 |
|---|---|
| **H** | ✅ 能扫到 U 盘的 extlinux |
| G | ❌ USB 当设备，读不了 U 盘 |

刷 H：

```powershell
upgrade_tool db files\MiniLoaderAll_p3_l1.bin
upgrade_tool wl 0x40 files\u-boot-L10-H.bin
```

## 一、做 U 盘系统

### 1. 拿镜像

用 `p3_armbian_slim.img`（3.32 GiB，已裁掉空白区）。

> 从完整镜像（15.6 GB）裁出来的，系统内容完全一致，写盘只要 1/5 时间。
> 下载地址见 `files/大文件下载地址.txt`。

### 2. 写进 U 盘

**Rufus**：

1. 选择 U 盘（**看容量确认，别选错硬盘**）
2. 选择 `p3_armbian_slim.img`
3. 弹出「ISO 模式 / DD 镜像模式」→ 选 **DD 镜像模式**
4. 开始（约 3~5 分钟）

**balenaEtcher**：直接选 `.img`，一路下一步。

⚠️ 写入会**清空整个 U 盘**。

### 3. 首次启动

插 U 盘到盒子，上电（H 模式）。U-Boot 会优先扫 USB：

```
Scanning bootdev 'usb_mass_storage.lun0.bootdev':
1  extlinux  ready  usb  1  ... /extlinux/extlinux.conf
** Booting bootflow ... with extlinux
1:      Armbian
```

首次启动 2~3 分钟（扩容 + 初始化），然后 `root` / `1234` 登录。

## 三、切换系统

### 方法 A：系统内 `p3boot`（最方便）

```bash
p3boot usb  --reboot     # 下次从 U 盘启动
p3boot emmc --reboot     # 下次强制走 eMMC（插着 U 盘也走 eMMC）
p3boot status            # 看当前标志
p3boot clear             # 清除标志，恢复默认（USB 优先）
```

**原理**：往 eMMC 的 LBA `0x6000`（24,576）写一个 512 字节标志扇区：

```
偏移 0..7   : magic "P3BOOT01"
偏移 8      : 'U' = 下次走 USB / 'E' = 下次走 eMMC
偏移 9..511 : 全 0
```

U-Boot 启动时读它、改 `boot_targets`、**然后立即清零**（一次性）。
所以：启动失败再重启一次就回默认，不会卡死在某个目标。

### 方法 B：开机菜单（不用进系统）

上电时**按住 ADC 下载键**（板子上的实体键），会出菜单：

```
1. Armbian (eMMC)
2. USB boot
3. Auto (USB first)
4. Scan list (no boot)
5. U-Boot console
```

用串口方向键选，回车确认。

### 方法 C：拔插 U 盘（最无脑）

默认 `boot_targets` 是 `usb mmc1 mmc0`：

| 状态 | 启动 |
|---|---|
| 插着 U 盘 | 优先 U 盘系统 |
| 拔掉 U 盘 | 自动走 eMMC |

## 四、改默认启动顺序

**默认：USB 优先**（插着 U 盘就启 U 盘系统）。如果想反过来：

### 临时（一次）

```bash
p3boot emmc --reboot
```

### 永久（改 U-Boot 环境变量）

在 U-Boot 命令行（按 `r` 停在 `=>`）：

```
=> setenv boot_targets 'mmc1 mmc0 usb'
=> saveenv
```

⚠️ 但当前固件的环境变量是**不持久化**的（`Loading Environment from nowhere`），
`saveenv` 不会生效。所以**永久修改需要重新编译固件**，或者每次用 `p3boot`。

> 实践建议：保持默认 USB 优先，用 `p3boot emmc` 切到 eMMC。因为 U 盘系统通常用于"临时测试"，
> 而 eMMC 是常用系统。

## 五、两个系统会不会互相干扰

| 项 | 会干扰吗 |
|---|---|
| 引导区（eMMC 0x40） | ❌ 共用一份，换系统不受影响 |
| `p3boot` 标志位（eMMC 0x6000） | ❌ 共用，但每次启动自动清零 |
| 各自的 rootfs | ❌ 完全独立 |
| 内核/dtb | ❌ 各自 boot 分区里有自己的 |

**唯一共享的是引导固件和标志位**，所以：

- 换 H/G 模式 → 两个系统都受影响（都要 H 才能 U 盘启动）
- `p3boot` 标志 → 一次性，用完即清

## 六、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 插 U 盘还是从 eMMC 启动 | 当前是 G 模式，或 `p3boot emmc` 标志没清 | 确认模式表 H 行有 `<==`；`p3boot clear` |
| U 盘系统启动后很慢 | U 盘写只有 7 MB/s | 见下方「性能调优」 |
| 两个系统时间/主机名混淆 | 同一个镜像克隆的，hostname 相同 | 各自改 `/etc/hostname` |
| `p3boot usb` 后没生效 | 标志位写到了旧地址 | 确认固件是 L10 且脚本 `LBA=24576` |

## 七、U 盘系统性能调优

U 盘实测：**读 34.5 MB/s（已到 USB2.0 上限）、写 7.1 MB/s**。

慢的不是速度，是**回写风暴**：默认 `dirty_ratio=20%` 会攒 392MB 脏页再一次性写，按 7.1MB/s 要 55 秒，期间系统卡死。

### 已做的优化（都持久化）

```bash
# 1) 脏页阈值改用绝对值
cat > /etc/sysctl.d/99-usb-storage-tuning.conf <<'EOF'
vm.dirty_background_bytes = 16777216
vm.dirty_bytes = 33554432
vm.dirty_expire_centisecs = 3000
vm.dirty_writeback_centisecs = 500
vm.vfs_cache_pressure = 50
EOF
sysctl -p /etc/sysctl.d/99-usb-storage-tuning.conf

# 2) 读预读 128KB -> 1MB
echo 1024 > /sys/block/sda/queue/read_ahead_kb
cat > /etc/udev/rules.d/60-usb-readahead.rules <<'EOF'
ACTION=="add|change", KERNEL=="sd[a-z]", ATTR{bdi/read_ahead_kb}="1024"
EOF

# 3) 日志进内存（不再写 U 盘）
systemctl enable --now armbian-ramlog

# 4) /var/tmp 进内存
grep -q '/var/tmp' /etc/fstab || \
  echo 'tmpfs /var/tmp tmpfs defaults,noatime,size=128M 0 0' >> /etc/fstab
mount -a
```

**效果**：写入总量不变（硬件限制），但回写从「攒 55 秒」变成「每 4.5 秒平滑写」，**卡顿消失**。

### 还能怎么提

| 方案 | 效果 | 代价 |
|---|---|---|
| 换好点的 U 盘 | 写 7→25 MB/s | 几十块钱 |
| eMMC 装系统 | 240 MB/s | 见 02（推荐） |
| overlay 只读根 | 写入进内存 | 重启丢改动，只适合测试 |
