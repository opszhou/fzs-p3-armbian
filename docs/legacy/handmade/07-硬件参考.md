# 07 · 硬件与地址参考

> 刷机时需要用到的所有"硬数据"：芯片型号、分区地址、校验值。
> 出处：丝印实读、UART 日志、内核 dmesg。

## 一、板子身份

| 项 | 值 |
|---|---|
| 商品名 | 蜂助手 P3 / Onething RK3566 BOX WXY4 V10 |
| DTS 名 | `rk3566-wxy-oec-turbo-4g`（Armbian 用的）<br>`rk3566-oec-box-wxy4`（另一套镜像用的） |
| **参考设计** | `rockchip,rk3566-box-demo-v10`（Rockchip 官方 demo 板） |
| 含义 | 这块板 = RK3566 BOX DEMO V10 的改版，所以 X96 X6 等同类盒子的固件大多能通用 |

> **重要**：因为基于官方 demo 设计，`EmuELEC X96X6` 之类第三方固件的 dtb **可能直接可用**，
> 但要换内核代际匹配的 dtb（4.19 内核不能用 6.x 的 dtb）。

## 二、核心器件

| 器件 | 型号 | 规格 | 验证来源 |
|---|---|---|---|
| SoC | Rockchip **RK3566** | 四核 Cortex-A55 | UART `SoC: RK3566` |
| DRAM | Samsung `K4A8G165WC-BCTD` × 2 | **DDR4** 8Gb x16，共 **2GB**，32-bit | 丝印 + UART `DDR4` |
| eMMC | Samsung `KLMAG1JETD` | **16GB eMMC 5.1**（HS200） | 丝印 + `mmcblk0: 14.7 GiB` |
| 以太网 PHY | Realtek **RTL8211F** | RGMII → GMAC `fe010000` | 内核 `TX delay(0x4f) / RX delay(0x2d)` |
| 串口 | UART2 `fe660000` | **1,500,000 8N1** | UART 日志 |
| USB | DWC3 `fcc00000` | **USB 2.0 only**（`maximum-speed=high-speed`） | 内核 + dts |

### ⚠️ 两个易错点

1. **内存是 DDR4，不是 LPDDR4X** —— 早期文档写错过。DDR4 与 LPDDR 的初始化参数、时序完全不同，弄错会起不来。
2. **USB 只有 2.0** —— 板边有 USB3.0 焊盘，但 SS 差分对没引到 SoC，焊座子也没用。

## 三、eMMC 存储布局

### 引导区（不受分区表管理）

| 区域 | LBA 范围 | 内容 |
|---|---|---|
| BootROM 保留 | `0x0` ~ `0x3F` | 保护 MBR + GPT 头 + 分区项（LBA 0~33） |
| **idbloader / TPL** | `0x40` 起 | DDR 初始化 + SPL |
| u-boot.itb | `0x4000` 起 | U-Boot proper |
| bootarea 总大小 | `0` ~ `0x47FF` | 18,432 扇区 = 9 MB |
| **p3boot 标志位** | `0x6000`（24,576） | 1 扇区，一次性启动标志 |
| boot 分区起点 | `0x8000`（32,768） | 分区表 p1 |

> `0x47FF` 到 `0x7FFF` 是空闲间隙（约 7 MB），`p3boot` 标志位放在中间偏后。

### 分区表（从 01_gpt_bootarea.img 读出）

| 分区 | 起始 LBA | 结束 LBA | 大小 | 内容 |
|---|---|---|---|---|
| `p1` | `0x8000`（32,768） | 819,199 | 384 MiB | boot（ext4：extlinux + KERNEL + dtb） |
| `p2` | `0xC8000`（819,200） | 盘尾 | 剩余 | rootfs（ext4） |

> 这是 Armbian v2 布局。原厂 Android 布局完全不同（p1=2GB FAT，p2=32MB），重刷会覆盖。

## 四、写入地址速查表

**这份表是刷机的核心，照着填不会错。**

| 文件 | 起始 LBA | 扇区数 | 字节数 |
|---|---|---|---|
| `u-boot-L10-H.bin` | `0x40`（64） | `0x47BD`（18,365） | 9,402,880 |
| `u-boot-L10-G.bin` | `0x40`（64） | `0x47BD`（18,365） | 9,402,880 |
| `01_gpt_bootarea.img` | `0x0` | `0x4800`（18,432） | 9,437,696 |
| `02_boot.img` | `0x8000`（32,768） | `0x48000`（294,912） | 402,653,184 |
| `03_rootfs.img` | `0xC8000`（819,200） | — | 3,144,679,424 |
| `04_backup_gpt.img` | `0x1D1EFDF` | 33 | 16,896 |

### 换算规则

```
扇区号 = 字节偏移 / 512
字节数 = 扇区数 × 512
```

例：`u-boot` 9,402,880 / 512 = 18,365 扇区 = `0x47BD`

### ⚠️ 最常见的三个错

| 错误 | 后果 |
|---|---|
| 引导写成 `0x0` 而不是 `0x40` | 覆盖分区表，板子起不来 |
| `01_gpt_bootarea` 写成 `0x40` | 分区表错位，找不到系统 |
| 只写 `u-boot.itb` 不写 idbloader | SPL 缺失，串口无输出 |

## 六、引导链

```
上电
  ↓
BootROM（芯片内固件，刷不掉）
  ↓ 读 eMMC 0x40 的 IDB
SPL / TPL（DDR 初始化，956MHz）
  ↓
U-Boot proper 2025.10（0x4000）
  ↓ 读 p3boot 标志（0x6000）→ 按模式决定行为
  ↓ 按 boot_targets 顺序扫描
extlinux（p1 分区 /extlinux/extlinux.conf）
  ↓
Linux 内核 + dtb
  ↓
rootfs
```

### 各阶段故障特征

| 卡在 | 串口现象 | 含义 |
|---|---|---|
| BootROM | 完全无输出 | IDB 无效 / eMMC 不响应 |
| SPL | 打印 `U-Boot SPL` 后停 | DDR 初始化失败 / itb 损坏 |
| U-Boot proper | 打印 U-Boot 版本后停 | 环境变量 / 启动脚本问题 |
| extlinux | `Retrieving file` 后停 | 内核或 initrd 读不出来 |
| 内核 | `Starting kernel ...` 后停 | 内核崩溃 / 根文件系统挂不上 |

## 七、引脚与接口

| 接口 | 位置 | 用途 |
|---|---|---|
| USB OTG | 板边 USB-A 口 | 刷机 / U 盘 / UMS（同一口，模式不同用途不同） |
| 串口 | 板上排针（GND/TX/RX） | 调试日志，1.5Mbps |
| ADC 下载键 | 板面按键 | 按住上电 → 出启动菜单 |
| 短接点 | 背面 eMMC 旁两圆点 | CLK + GND，进 MASKROM |
| HDMI | 板边 HDMI 口 | 输出显示 |
| 网口 | RJ45 | 千兆（RTL8211F） |
| eMMC | BGA 芯片 | 16GB |

## 八、与同类盒子的关系

因为基于 `rk3566-box-demo-v10` 参考设计：

| 固件 | 能直接用吗 | 说明 |
|---|---|---|
| 本手册的 L10 + Armbian | ✅ | 专为这块板 |
| EmuELEC X96X6 | ⚠️ | dtb 是 box-demo 的，**但内核 4.19 与我们的 6.x dtb 不通用**；它自带的引导在这块板上起不来（DDR/PMIC 参数不同） |
| LibreELEC RK356X | ⚠️ | 主线内核，dtb 可能需替换为本板的 |
| 其他 RK3566 盒子的 Android | ❌ | 分区表和引导链完全不同 |

> 结论：**跨固件复用时，最先要看的是「内核代际是否与 dtb 匹配」**，不是板子型号。
