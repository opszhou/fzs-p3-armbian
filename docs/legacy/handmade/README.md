## 一句话原理

这块板子有三种"活着"的状态，刷机就是**把固件写进 eMMC 的特定位置**：

```
① 能进系统（SSH/串口可用）  → 最省事：系统内 dd 直接写
② LOADER 模式（工具能识别） → 次省事：upgrade_tool wl 写
③ 什么都没有                → 短接 MASKROM，用 BootROM 兜底
```

**三种状态都能刷，③ 是永远有效的最后手段**（BootROM 固化在芯片里，刷不死）。

不确定自己属于哪种？看 [01-判断设备状态.md](01-判断设备状态.md)。

## 两个关键概念（务必先懂）

### 1. 引导固件有两个模式，**互斥**

| 模式 | 文件名 | U 盘启动 | rockusb 刷机 | UMS（当 U 盘给电脑） |
|---|---|---|---|---|
| **H**（host） | `u-boot-L10-H.bin` | ✅ | ❌ | ❌ |
| **G**（gadget） | `u-boot-L10-G.bin` | ❌ | ✅ | ✅ |

**为什么互斥**：板子只有一个 USB 口，同一个控制器不能同时当"主机"和"设备"。

刷哪个？

- 平时用、要 U 盘启动 → **H**
- 要刷机、要救砖 → **G**

启动时串口会打印当前模式，不会搞错：

```
+-------+----------+---------+-------+
| MODE  | USB-boot | rockusb | UMS   |
+-------+----------+---------+-------+
| L10-H |   YES    |   no    |  no   |  <== active
| L10-G |    no    |   YES   |  YES  |
+-------+----------+---------+-------+
```

### 2. 引导固件和系统是两回事

```
eMMC 引导区（0x40 起，9.4 MB）  ← u-boot-L10-*.bin 写这里
eMMC 分区（p1/p2，系统本体）    ← 01/02/03 镜像写这里
U 盘（可选，第二系统）          ← p3_armbian_slim.img 写这里
```

- **只换引导**：9.4 MB，5 秒完成，不动系统和数据
- **装系统**：需要写 3.5 GB，动分区表（会清掉原有系统）

## 全流程速查（熟练后看这个就够）

```powershell
# 0) 断电 → 短接主板背面两圆点 → 上电 → 松开，进 MASKROM

# 1) 确认设备
upgrade_tool ld

# 2) 加载 loader（MASKROM 下必须，否则写不了）
upgrade_tool db files\MiniLoaderAll_p3_l1.bin

# 3) 刷引导（二选一）
upgrade_tool wl 0x40 files\u-boot-L10-H.bin        # 日常：U 盘启动
upgrade_tool wl 0x40 files\u-boot-L10-G.bin        # 刷机：rockusb

# 4) 校验（读回比对）
upgrade_tool rl 0x40 0x47BD readback.bin
sha256sum readback.bin      # 与 files\SHA256SUMS.txt 中对应值比对

# 5) 断电 10 秒 → 上电
```

装系统再加三步（详见 [02-刷系统到eMMC.md](02-刷系统到eMMC.md)）：

```powershell
# 01 镜像按你要的模式二选一，内嵌的引导会连同分区表一起写好，无需再单独刷引导
upgrade_tool wl 0x0     01_gpt_bootarea_l10h.img   # 日常/U盘启动
# upgrade_tool wl 0x0   01_gpt_bootarea_l10g.img   # 刷机/rockusb
upgrade_tool wl 0x8000  02_boot.img
upgrade_tool wl 0xC8000 03_rootfs.img
```

> 💡 **最简刷机**：如果只是想给盒子装好系统、日常用，走"方案 A：一条龙"——
> 短接进 MASKROM → `upgrade_tool db MiniLoaderAll_p3_l1.bin` →
> 上面三条 `wl`（01 选 `l10h`）→ 断电上电。引导和系统一次到位，不用单独执行第 3 步刷引导。

## 三条铁律

1. **写之前先短接确认进 MASKROM**——LOADER 模式下某些操作会被厂商 uboot 拒绝（`Switch storage failed`）
2. **写完必须读回校验**——U 盘/线缆不稳时会静默写坏，校验能提前发现
3. **断电 10 秒再上电**——不是玄学，是让 eMMC 缓存落盘、电源彻底放电
